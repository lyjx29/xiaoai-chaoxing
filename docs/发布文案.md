## 详细介绍（点进脚本页显示）

```
与其他学习通脚本最大的不同：

✅ 完全免费、完全开源（MIT）
✅ 自带 API Key 直连大模型（DeepSeek / OpenAI / Kimi / Ollama 任意 OpenAI 兼容端点）
   —— 不依赖任何第三方题库、不依赖免费中转站，无充值、无广告、无绑定，数据完全由你自己掌控

功能一览：
· 自动答题：单选/多选/判断/填空/简答/论述/写作/翻译/编程题/阅读理解（复合大题）
· 自动挂机：视频/音频/文档/阅读/读书/直播/速课
· 拟学生化语言作答、答案分点规范（老师/AI 阅卷友好）
· 防清进度、拟人化答题节奏、字体反爬解密

使用只需 3 步：
1. 安装脚本管理器（脚本猫/Tampermonkey）
2. 导入脚本
3. 设置里填你自己的 API Key（DeepSeek 等，按量计费，很便宜）→ 自动运行
```
