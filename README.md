# 小哀学习通助手（XiaoAi Chaoxing Assistant）

> 学习通 / 超星全自动助手 · 自带 API Key 直连 AI · 无需任何第三方题库 / 中转站

一个运行在 [脚本猫 ScriptCat](https://scriptcat.org) / Tampermonkey 上的 userscript。**完全自研重构**，综合了社区中多项成熟的思路与工程实践，并用**你自己的 API Key 直连大模型**作答，不依赖任何会失效的第三方题库或免费中转站。

默认模型 `deepseek-v4-flash`，对大学题目准确率与成本都合适；也兼容任意 OpenAI 兼容端点（DeepSeek / OpenAI / Kimi / Ollama / 智谱…）。

---

## ✨ 功能一览

### 📝 答题（核心）
| 题型 | 支持 | 说明 |
|---|---|---|
| 单选题 / 多选题 | ✅ | 六层匹配：数字索引 → 精确 → 去标点 → 字母("AB") → "C.文本"复合 → Levenshtein 模糊；希腊字母/音标归一化 |
| 判断题 | ✅ | 对/错/√/×/true/false/T/F 全识别；否定词优先（"不正确"→错） |
| 填空题 | ✅ | 自动识别空位数量（textarea / `.blankList2` / `[data-editorindex]` / UEditor），答案 `|`、`#` 多分隔符按序填入，UEditor 三层定位 + 隐藏 textarea 同步 |
| 简答 / 论述 / 名词解释 / 材料 | ✅ | **拟学生化语言**：prompt 专门要求避免 AI 套话，按分值把握详略 |
| 写作题 / 翻译题 | ✅ | 按题目语言写作 / 互译 |
| 编程题 | ✅ | CodeMirror / Monaco / textarea 三种编辑器自动填充 + 自动点提交（社区空白点，自研实现） |
| 阅读理解 / 完形填空（复合大题） | ✅ | 大题材料作背景注入，逐小题递归作答 |
| 视频中弹题 | ✅ | 自动作答，答错自动"排除法"重试直至答对 |
| 图片题 / 听力题 | ⚠️ | 题目中的图片/音频转成资源地址文本发给 AI 辅助判断 |

### 🎬 刷课挂机
- 视频 / 音频：倍速（最高 16×，临近结尾自动回 1×）、静音、防暂停、自动跳转任务点
- 文档 / 阅读 / 读书 / 速课 / 直播 / 知识图谱：一键完成
- 章节自动翻页、无任务点自动跳过、闯关模式识别

### 🛡️ 防检测 / 防清进度
- 后台切页伪装（`onblur`/`visibilityState`/`hasFocus` 劫持 + 静音 AudioContext 防休眠）
- 答题覆盖率阈值：答不齐就不交卷、只保存（默认 60%，可调）
- 可选"随机答错"（找不到答案时单选选 B / 多选全选 / 判断选错），避免全对
- 拦截超星 `detect.chaoxing.com` 检测脚本、中和 `viewer.show` 反挂机弹窗
- 字体反爬 `font-cxsecret` 自动解密（字形 md5 指纹查表，多源映射表自动兜底）

### 🧠 AI 能力
- **自有 API Key**，OpenAI 兼容 `chat/completions`（Anthropic 端点自动识别），URL 自动补全
- 客观题默认 **JSON 结构化输出**（`{"answer","answers"}`），模型不配合时自动降级为文本解析
- 长响应自动提取末尾答案、请求节流防封、超时自动重试
- **本地答案缓存**：答过的题按「题干+选项+题型」指纹复用，省 API 调用

## 📦 安装（小白详细版）

安装共需 **3 样东西**：① 一个浏览器 → ② 一个"脚本管理器"扩展 → ③ 一个脚本文件。

---

### 第 1 步：下载脚本文件（`小哀学习通助手.user.js`）

> 这一步是新手最容易卡住的——`.user.js` 是一个**文件**，不是网页。请用下面任一种方式把它"保存到本地"。

**方式 A：从 GitHub Releases 下载（推荐，最正规）**

1. 打开仓库页面：https://github.com/lyjx29/xiaoai-chaoxing
2. 点右边 **Releases**（或点 `v1.0.0` 标签）
3. 在版本列表里找到「**Assets**」区，里面有一个文件 `小哀学习通助手.user.js`
4. **右键**那个文件名 → 选「**链接另存为… / 另存为 / Save link as**」→ 保存到桌面（**千万别直接左键点开**，左键可能会打开一堆代码页面）
5. 确认桌面出现一个叫 `小哀学习通助手.user.js` 的文件（图标通常是浏览器/记事本样式，都正常）

**方式 B：从仓库 dist 目录下载**

1. 打开 https://github.com/lyjx29/xiaoai-chaoxing/tree/main/dist
2. 点文件名 `小哀学习通助手.user.js` 进入文件页
3. 点文件内容右上角的「**Download raw file / 下载原始文件**」按钮（或右键 → 另存为）
4. 保存到本地

**方式 C：如果前面两种下载后打开是乱码 / 网页源码（兜底）**

如果浏览器把文件当成网页打开了（页面上全是代码），这样处理：
1. 在该页面上按 **Ctrl+S**（Mac 是 ⌘S）
2. 「另存为」窗口里，把「文件名」改成 `小哀学习通助手.user.js`（**扩展名必须是 `.user.js`**）
3. 保存类型选「所有文件 / All files」，保存
4. 得到一个 `.user.js` 文件即可

---

### 第 2 步：安装「脚本管理器」扩展（脚本猫 或 Tampermonkey 任选其一）

脚本管理器是个**浏览器扩展**，就像装插件一样。**装了它才能运行我们的脚本。**

#### 🟢 推荐：脚本猫 ScriptCat（国内用户友好，用 Edge 浏览器最顺）

**Edge 浏览器（Windows 自带，推荐）：**
1. 打开浏览器，在地址栏输入：`edge://extensions` 并按回车（这是 Edge 的扩展管理页）
2. 点页面左下角「**获取 Microsoft Edge 扩展**」（或直接访问 https://microsoftedge.microsoft.com/addons）
3. 在商店搜索框输入「**脚本猫**」→ 按回车
4. 在结果里找到「脚本猫 ScriptCat」（图标是一只猫）→ 点「**获取 / Get**」→ 弹窗里点「**添加扩展 / Add extension**」
5. 装好后，浏览器右上角会出现一个猫爪/小方块图标。点它旁边的「拼图」图标，把脚本猫「固定 / Pin」到工具栏（方便使用）

**Chrome 浏览器：**
1. 访问 https://chromewebstore.google.com （若打不开说明网络问题，请用 Edge 或其他方式）
2. 搜索「脚本猫」或「ScriptCat」→ 找到后点「添加至 Chrome」

**搜不到怎么办（重要）：**
- 换浏览器：用 **Edge** 几乎 100% 能搜到（国内可直接访问微软商店）
- 直接访问脚本猫官网下载：https://scriptcat.org 页面上有「安装到 Chrome/Edge」按钮，点它浏览器会自动跳转安装
- 若商店提示"该扩展不可用/不在该地区"，换搜「**Tampermonkey**」或「**篡改猴**」看能否搜到

#### 🟡 备选：Tampermonkey（油猴 / 篡改猴）

- **Edge**：商店搜「Tampermonkey」→ 获取（或直接打开 https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd）
- **Chrome**：商店搜「Tampermonkey」→ 添加至 Chrome（或直接打开 https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo）
- **Firefox（火狐）**：https://addons.mozilla.org/firefox/addon/tampermonkey/
- **Safari（苹果电脑）**：在 Mac 的「App Store」搜「Tampermonkey」

**装完后如何确认扩展生效：**
- 浏览器右上角应能看到扩展图标（脚本猫是猫爪，油猴是一个方框带数字）
- 如果看不到，点右上角「拼图」🧩 图标 → 把脚本管理器「固定」到工具栏
- **如果图标是灰色 / 显示 0**，说明脚本没启用或没装脚本，继续下一步

---

### 第 3 步：把脚本文件导入脚本管理器（三选一）

> 脚本文件下载好了、管理器装好了，现在把两者"合起来"。

**方法一：拖拽导入（最简单，推荐）**
1. 确认桌面有 `小哀学习通助手.user.js` 文件
2. 鼠标**按住这个文件**，把它**直接拖进**浏览器窗口里（拖到任意页面都行）
3. 浏览器/管理器会弹出一个「安装脚本 / 是否安装」的确认页 → 点「**安装 / 确定 / Install**」
4. 完成！点管理器图标，能看到脚本已在列表里

**方法二：新建脚本 + 粘贴代码**
1. 点浏览器右上角的管理器图标 → 打开管理面板
2. 找到「**新建脚本 / 添加新脚本 / 新建用户脚本**」按钮
3. 页面会打开一个代码编辑框（里面是默认的模板代码，**全部删掉**）
4. 打开下载好的 `.user.js` 文件（双击用记事本打开），**全选（Ctrl+A）→ 复制（Ctrl+C）**
5. 回到编辑器，**粘贴（Ctrl+V）**
6. 按 **Ctrl+S** 保存，关掉编辑页
7. 此时点管理器图标，脚本应已在列表中并处于**启用**状态

**方法三：管理面板导入文件**
- **脚本猫**：点图标 →「管理面板 / 我的脚本」→ 找到「**导入**」按钮 → 选择 `小哀学习通助手.user.js`
- **Tampermonkey**：点图标 →「管理面板 / Dashboard」→ 顶部「**工具 / Utillities**」标签 → 在「导入 / Import」区点「选择文件 / Choose File」→ 选择 `.user.js` → 点「导入 / Import」→ 弹出确认页点「安装 / Install」

**导入后确认：**
- 点管理器图标 → 列表里应有「小哀学习通助手」，开关处于**打开（绿色）**状态
- 如果开关是灰色/关闭，点一下打开它
- 如果列表里是空的，重新做第 3 步

---

### 第 4 步：验证脚本是否生效

1. 打开一个学习通页面（如 https://i.chaoxing.com ，登录你的账号）
2. 进入任意**课程章节 / 作业 / 测验**页面
3. 网页右下角会出现一个**半透明悬浮窗**（标题「小哀学习通助手」）
4. 看到悬浮窗 = 安装成功！没看到 = 回到第 3 步确认脚本已启用，或**刷新页面（F5）**再试

---

### 第 5 步：填入你的 AI Key 并开始使用

1. 先注册并创建 API Key（以 DeepSeek 为例）：
   - 打开 https://platform.deepseek.com → 用手机号注册/登录
   - 点左侧「API Keys」→「创建 API Key」→ 复制那串 `sk-` 开头的字符串（只显示一次，务必保存好）
2. 回到学习通页面，点悬浮窗「**设置**」
3. 填入三项：
   - **Base URL**：默认 `https://api.deepseek.com`（不用改）
   - **API Key**：粘贴刚才复制的那串 `sk-...`（**填的是你自己的，不要填别人的**）
   - **模型名**：默认 `deepseek-v4-flash`（不用改）
4. 点「**测 API**」按钮 → 显示"API 连接成功"即全部配置完成
5. 进入作业/测验页面，脚本会自动开始答题

> 💡 用其他服务商：把 Base URL 换成 `https://api.openai.com/v1`、`https://api.moonshot.cn/v1`、`http://127.0.0.1:11434/v1`（Ollama）等，模型名填对应模型的，Key 填对应平台的即可。

### ❓ 常见问题（FAQ）

| 问题 | 解决 |
|---|---|
| 商店搜不到脚本猫 | 用 **Edge 浏览器**（微软商店国内可直连）；或去 https://scriptcat.org 点「安装」按钮 |
| 扩展装上了但图标是灰色 | 点图标 → 检查脚本是否**启用**；或刷新学习通页面 |
| 下载的文件打开是乱码 | 不要"打开"，要**右键 → 另存为**保存成文件；或复制代码用「新建脚本」粘贴 |
| 拖拽文件没反应 | 改用「方法二：新建脚本+粘贴」或「方法三：导入」 |
| 悬浮窗没出现 | 确认在 `chaoxing.com` / `edu.cn` 域名的学习通页面；按 F5 刷新；检查脚本已启用 |
| 点「测 API」提示网络错误 | 浏览器弹「是否允许脚本访问 xxx 域名」时点**允许**；或去脚本管理器给对应域名加 `@connect` |
| 提示 API Key 无效 | 检查是否复制完整（`sk-` 开头到结尾）、是否多复制了空格 |
| 答题没反应 | 确认作业/测验页已加载完成（题目显示出来再等几秒）；看悬浮窗日志了解卡在哪一步 |

## 🛠️ 开发者调试（本地详细日志 / 诊断报告）

脚本内置一个**开发模式开关**，用于排查真实页面适配问题：

1. 打开 [src/userscript.js](src/userscript.js)，把顶部 `var DEV_MODE = false;` 改为 `true`
2. `npm test` 重新构建 → 安装到脚本管理器
3. 在真实学习通页面上运行，日志会记录全流程：
   - 路由匹配 → 题干全文 → 选项 → 题型识别 → 发送的 prompt → AI 原始返回 → 解析结果 → 匹配选项 / 填入每个空
   - 解析或匹配失败的题目会**保存其真实 DOM 快照**，便于对照修复选择器
4. 诊断报告三选一导出：
   - 悬浮窗新增「导出报告」按钮（仅开发模式显示）
   - 控制台执行 `__xiaoaiExportReport()`
   - 控制台执行 `__xiaoaiDumpLog()` 只看日志 / `__xiaoaiClearLog()` 清空
5. 报告包含：页面信息 + 路由 + 设置快照（**API Key 已打码**）+ DOM 选择器探针 + 题目快照 + 页面错误捕获 + 完整日志
6. 发布前把 `DEV_MODE` 改回 `false` 重新构建 → 发布版零日志负担
